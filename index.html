k8s-observability-stack

Complete Kubernetes observability stack with VictoriaMetrics, Loki, Grafana, and more.

Helm Repository

Quick Start

# Add the Helm repository helm repo add k8s-observability https://theorigamicorporation.github.io/k8s-observability-stack helm repo update # Install with default configuration helm install observability k8s-observability/k8s-observability-stack \ --namespace observability --create-namespace # Access Grafana kubectl port-forward svc/observability-k8s-observability-stack-grafana-service 3000:3000 -n observability

Components

VictoriaMetrics Core

High-performance time-series database for metrics storage

Grafana Core

Observability platform with dashboards and alerting

Loki Core

Horizontally-scalable log aggregation system

Alloy Core

OpenTelemetry collector for metrics, logs, traces

Alertmanager Optional

Alert routing and notification management

VictoriaTraces Optional

Distributed tracing with OTLP support

Jaeger Optional

Alternative distributed tracing platform

Kiali Optional

Service mesh observability for Istio
